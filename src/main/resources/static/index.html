Recruit Guard
API docs GitHub

Check a recruiter's email before you reply.

Fake job offers copy real company names, ask for your Social Security number, and mail you bad checks. Paste the email here and Recruit Guard marks every warning sign in it.

How do I get the full email?
Gmail
Open the email, click the three dots next to Reply, choose Show original, then Copy to clipboard.
Outlook
Open the email, click the three dots, choose View, then View message source.
Apple Mail
Open the email, then View, Message, Raw Source.

The full email lets Recruit Guard read the Reply-To address and the sender checks (SPF, DKIM, DMARC) that mail servers record.

Built by Jon with Java 21 and Spring Boot. Source code REST API Recruit Guard gives warning signs, not guarantees. Always confirm a job on the company's own careers site.
